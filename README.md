# 🚗 CarService Pro

Sistema completo de gestão para oficinas automotivas. Interface moderna, dark mode, com sincronização em tempo real via Supabase.

![Dashboard](https://via.placeholder.com/800x400/0f0f0f/2563eb?text=CarService+Pro+Dashboard)

## ✨ Funcionalidades

- 📊 **Dashboard** em tempo real com estatísticas
- 👥 **Cadastro de Clientes** com dados de veículos
- 📅 **Agendamentos** de serviços
- 💰 **Orçamentos** com aprovação/rejeição
- 🔄 **Sincronização** automática com Supabase
- 📱 **Responsivo** para mobile e desktop
